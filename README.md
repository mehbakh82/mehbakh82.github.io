# Mehran Bakhtiari

Source for the [personal academic portfolio](https://mehbakh82.github.io/).

Open `index.html` directly or serve the repository root with a static web server. The site uses HTML, CSS, local WebP artwork and fonts, and a small JavaScript file for project filters. There is no installation or build step.

- `index.html` holds the homepage and advisor details.
- `research/` contains the four case studies and links to the evidence in their repositories.
- `projects.html` holds the project index. Use the same category string for new rows and their filter option. The full list is available with JavaScript disabled.
- `cv.html` holds the public version of the CV and supports browser printing.

GitHub Pages serves `main` from the repository root. The website’s imagery illustrates computational methods. The published study artifacts are linked from the case studies. Font licenses are in `assets/`.
